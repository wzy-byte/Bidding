# 招标采购数智化小知识 · 第 01 期

**日期**：2026-11-02（周一）
**阶段**：第一阶段 —— 《招标投标法》及其实施条例基础
**本期主题**：入门三问之「谁必须招」「怎么招」

------

## 知识点 1：哪些项目「必须招标」？——记住「三个条件同时满足」

### 一句话结论

一个项目要成为「依法必须招标项目」，必须**同时**满足三个条件：**项目性质对 + 资金性质对 + 合同金额够**。三者缺一不可。

### 通俗解释

判断是否必须招标，就像过三道闸门，三道全开才算：

**第一道闸门：项目是什么？**
必须是**工程建设项目** —— 即工程本身，以及「与工程建设有关的货物」和「与工程建设有关的服务」。

| 类别             | 具体指什么                                                   | 举例                           |
| ---------------- | ------------------------------------------------------------ | ------------------------------ |
| 工程             | 建筑物和构筑物的新建、改建、扩建及其相关的装修、拆除、修缮   | 建厂房、修路、楼房改造         |
| 与工程有关的货物 | 构成工程**不可分割**的组成部分、且为实现工程基本功能**必需**的设备材料 | 钢筋水泥、电梯、中央空调主机   |
| 与工程有关的服务 | 为完成工程所需的勘察、设计、监理                             | 地质勘察、施工图设计、工程监理 |

⚠️ 注意：**办公电脑、公务用车、日常办公用品**不属于「与工程建设有关的货物」，不适用招标投标法（可能适用政府采购法），这是最常见的判断错误。

**第二道闸门：钱是谁的？**（满足其一即可）

- 全部或部分使用**国有资金投资或国家融资**：
  - 使用**预算资金 200 万元以上**，且该资金**占投资额 10% 以上**；
  - 使用**国有企业事业单位资金**，且该资金**占控股或主导地位**。
- 使用**国际组织或外国政府贷款、援助资金**（世行、亚行、外国政府贷款等）。

**第三道闸门：单个合同金额够不够？**

| 采购类型               | 单项合同估算价门槛 |
| ---------------------- | ------------------ |
| 施工                   | ≥ **400 万元**     |
| 重要设备、材料等货物   | ≥ **200 万元**     |
| 勘察、设计、监理等服务 | ≥ **100 万元**     |

关键补充：**同一项目中「可以合并进行」的采购，合同估算价要合计计算**。把 400 万的施工拆成 4 个 100 万的标段分别发包，属于「化整为零规避招标」，是明确禁止的违法行为。

### 法条依据

- 《招标投标法》第 3 条（必须招标的项目范围）、第 4 条（禁止化整为零规避招标）
- 《招标投标法实施条例》第 2 条（工程、货物、服务的定义）
- 《必须招标的工程项目规定》（国家发改委令第 16 号）第 2、3、5 条（资金口径与金额标准）

### 常见坑

1. 只看金额不看资金性质 —— 民企自有资金的商品房项目，即便 1 个亿也不属于「依法必须招标」。
2. 把「与工程无关的货物」硬套进来 —— 判断货物要看它是否**构成工程实体且不可分割**。
3. 分标段、分标段再分包，试图把金额降到门槛以下 —— 合并计算后超标仍须招标。
4. 忘了审批环节 —— 需履行审批、核准手续的项目，其**招标范围、招标方式、招标组织形式**要一并报批。

### 产品 / 研发视角（系统要做成什么样）

- 建立「**项目性质 + 资金性质 + 合同估算价**」三元组判定引擎，输出「必须招标 / 可不招标 / 需人工复核」三种结论，而不是简单的是非题。
- 金额阈值（400/200/100 万）、预算资金占比（10%）、预算资金额（200 万）必须**参数化可配置**，因为地方标准和政策会调整，写死在代码里必然返工。
- 增加「**化整为零预警**」：同一项目下识别同类采购包的时间聚集、供应商重合、金额刚好卡在门槛下方（如 395 万），主动提示合并计算。
- 判定结论要**留痕 + 展示所依据的法条**，这是后续审计、巡察最常查的点。

## 知识点 2：公开招标 vs 邀请招标 —— 默认答案是「公开」

### 一句话结论

招标只有两种法定方式：**公开招标**和**邀请招标**。对国有资金占控股或主导地位的依法必须招标项目，**默认必须公开招标**，邀请招标是例外，且例外情形极少、需要认定。

### 通俗解释

| 对比项   | 公开招标                   | 邀请招标                              |
| -------- | -------------------------- | ------------------------------------- |
| 邀请对象 | **不特定**的法人或其他组织 | **特定**的法人或其他组织（至少 3 家） |
| 发布方式 | 依法发布招标公告           | 发出投标邀请书                        |
| 竞争程度 | 充分竞争，范围最广         | 范围受限，竞争较弱                    |
| 适用前提 | 常态、默认                 | 需符合法定情形并取得认定              |

**可以邀请招标的两种法定情形**（针对国有资金占控股或主导地位的依法必须招标项目）：

1. **技术复杂、有特殊要求或受自然环境限制**，只有**少量**潜在投标人可供选择；
2. 采用公开招标方式的**费用占项目合同金额的比例过大**。

除上述情形外，还有一类特殊规定：国家重点项目、地方重点项目**不适宜公开招标**的，须经国务院发展计划部门或省级人民政府**批准**，方可邀请招标。

**谁来认定？** 不是招标人自己说了算：

- 属于需审批、核准的项目 —— 由**项目审批、核准部门**在审批、核准时认定；
- 其他项目 —— 由招标人**申请有关行政监督部门**作出认定。

### 法条依据

- 《招标投标法》第 10 条（招标方式定义）、第 11 条（重点项目邀请招标的批准）
- 《招标投标法实施条例》第 7 条（招标范围、方式、组织形式报批）、第 8 条（邀请招标的适用情形与认定主体）

### 常见坑

1. 以「工期紧」「只有几家熟悉」为由直接邀请招标 —— 法定情形里**没有**「工期紧」这一条。
2. 招标人自行认定「技术复杂」就发邀请书 —— 认定权在审批核准部门或行政监督部门，自行认定属于程序违法。
3. 邀请招标只邀请 2 家 —— 法定最低 **3 家**，否则无法开标。
4. 混淆「邀请招标」和「竞争性谈判/磋商」—— 后者不是招标方式，属于政府采购的采购方式，适用规则完全不同。

### 产品 / 研发视角（系统要做成什么样）

- 招标方式不能做成自由下拉框。选择「邀请招标」时，**强制触发**：法定情形选择 + 认定文件上传 + 认定机关 + 认定日期，四要素缺失不允许提交。
- 邀请招标的受邀单位数量做**强校验**（≥3 家），并与开标解密数量联动校验。
- 建立「方式合规性检查」规则库：国有资金控股 → 默认锁定公开招标，解锁需授权审批流。
- 招投标法（工程）与政府采购法（货物服务）是两套规则，系统里要做**业务类型分流**，不要让两种方式混在同一个枚举里。

------

## 今日小结（可直接背）

1. 必须招标 = **工程建设项目** + **国有/国际资金达标** + **合同估算价达 400/200/100 万**，三条同时满足；分拆规避违法。
2. 招标方式只有**公开**和**邀请**两种；国有资金控股项目默认公开，邀请招标须符合法定情形并经有权部门认定，受邀单位不少于 3 家。
