# 术语对照表（业务 ↔ 前端）

> 用法：读条文卡住时先查这里。看到陌生词先别猜，加一行比猜一次便宜。
> 状态：随学随补，每月至少加 5 行。

| 业务术语 | 含义 | 前端等价概念 |
| --- | --- | --- |
| 招标人 | 项目出资或使用方，负责组织招标 | 需求发起方 / 业务主体 |
| 招标代理机构 | 受托组织招标活动的中介机构 | 服务提供方 |
| 投标人 | 响应招标、参加竞争的法人或其他组织 | 请求发起者 |
| 评标委员会 | 依法组建的评审组织，5 人以上单数 | 规则执行节点 + 人工复核 |
| 实质性要求 | 不满足即导致否决的条件 | 必填且强校验字段 |
| 否决投标 | 因不符合实质性要求被判无效 | 校验失败即终止流程 |
| 澄清与修改 | 对招标文件的正式更正，受时限约束 | 配置变更 + 影响面通知 |
| 异议与投诉 | 对结果的法定救济，有前置顺序 | 申诉工单 + 升级流程 |
| 暗标评审 | 隐藏投标人身份的评审方式 | 数据脱敏 + 分区隔离 |
| 电子签章 | 与 CA 证书绑定的合法性要件 | 服务端验签 + 时间戳 |
| 围串标 | 投标人之间的串通行为 | 异常检测 + 证据链留痕 |
| 中标候选人公示 | 定标前的公开征询环节 | 发布前公示 + 反馈收集 |
| 资格预审 / 资格后审 | 在投标前 / 评标时审查资格 | 前置校验 / 流程内校验 |
| 投标有效期 | 投标文件承诺保持有效的期限 | 令牌有效期 |
| 履约保证金 | 中标后为保证履约提交的担保 | 押金 / 担保项 |
| 工程量清单 | 分项列明工程量的报价基础 | 结构化明细数据 |
| 清标 | 评标前对报价与清单的一致性核查 | 数据比对与异常检测 |
| 流标 / 废标 | 招标失败 / 投标被判无效 | 流程异常终止 / 校验失败 |
| 定标 | 招标人确定中标人 | 最终状态裁决 |
| 监管平台 | 行政监督部门的在线监督系统 | 审计与风控后台 |

---

## 补充约定

- 同一个概念，法规用词与产品用词不一致时，**以法规用词为准**，并在括号里写产品用词。例：`否决投标（产品里叫"废标"）`。
- 不要自造缩写。行业里没有的缩写会让后来人（包括三个月后的你）读不懂。
- 每加一行，顺手在 `03-条文笔记` 里补一句它的依据条号，否则这个表会退化成词典。
